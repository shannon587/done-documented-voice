# Demo video script (about 2 minutes, under 3)

Voice: en-US-JennyNeural (edge-tts), a neutral presenter. The narrator never speaks as Shannon. On screen the brand is always "Done + Documented"; the narration says "Done and Documented".

| # | Screen | Narration |
|---|---|---|
| 1 | Done + Documented Voice | This is Done + Documented Voice, from Done + Documented. It's a simple assistant that answers small business compliance questions out loud, and it plugs right into Alexa plus. |
| 2 | Why it exists | It was built by founder Shannon Watson, who is legally blind, for business owners who'd rather listen than read walls of text. Answers come one at a time, short and clear. |
| 3 | How it works | Under the hood, it's a small MCP server written in TypeScript. It uses the official MCP SDK, the same standard Alexa plus uses to talk to outside tools. |
| 4 | Four simple tools | There are four tools: check compliance, find the next deadline, explain a term, and run a quick accessibility check. Every answer is short enough to say out loud. |
| 5 | Ask: Idaho checklist | Let's try it. Here's a question about an out-of-state LLC doing business in Idaho. It says there are four things to handle, starts with foreign registration, and gives the fee. Then the owner just says next. |
| 6 | Ask: deadlines | What's the next deadline? The Idaho annual report, due October thirty-first, and it's free online. And New Mexico? Good news, there's no annual report there. |
| 7 | It won't guess | Every fee and rule points back to a real state source. And if it doesn't know, it says so. Ask about Texas, and it explains there's no verified data yet. No made-up numbers. |
| 8 | Website check | It can also look at a business website for missing image descriptions, unlabeled form fields, and messy headings, and it reads out the biggest problem first. |
| 9 | Done + Documented Voice | It's open source and free to use. That's Done + Documented Voice, from Done + Documented. Thanks for listening! |
