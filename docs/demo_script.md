# Demo video script (target about 2 minutes, under 3)

| # | Screen | Narration |
|---|---|---|
| 1 | Title: Done + Documented Voice | Done + Documented Voice. A voice-first compliance assistant for small businesses, built as an MCP server for Alexa plus. |
| 2 | The founder | It was built for Shannon Watson, a legally blind founder in Idaho. Compliance websites are walls of text. She needed answers she could hear, one at a time. |
| 3 | Architecture | It's a self-hosted MCP server in TypeScript. It uses the official MCP SDK version 1.32 with Streamable HTTP and protocol 2025-11-25, the standard behind Alexa plus integrations. |
| 4 | Four tools | Four tools: check business compliance, next deadline, explain item, and accessibility quick check. Every reply is short enough to speak. |
| 5 | Live call: Idaho checklist | Ask about an out-of-state LLC in Idaho. It answers: four items. First, foreign registration. Fee: 100 dollars online, 120 by paper. Say next for more. |
| 6 | Live call: deadlines | Next deadline: the Idaho annual report is due October 31, 2026, free online. And New Mexico? New Mexico LLCs have no annual report. |
| 7 | Honesty | Every fee and rule cites a statute or state source in the code. If we don't know, it says so. Texas? Unknown. No made-up fees, ever. |
| 8 | Accessibility check | It also checks a business website for missing alt text, unlabeled form fields and headings, then speaks the top issue first. |
| 9 | Close | Open source under the MIT license. Done + Documented Voice: compliance you can hear. |
