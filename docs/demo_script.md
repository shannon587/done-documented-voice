# Demo video script (about 2 minutes, under 3)

Voice: en-US-AvaMultilingualNeural (edge-tts). On screen the brand is always "Done + Documented"; the narration says "Done and Documented".

| # | Screen | Narration |
|---|---|---|
| 1 | Done + Documented Voice | Hi! This is Done + Documented Voice. It's a little assistant that answers small business compliance questions out loud, and it plugs right into Alexa plus. |
| 2 | Why I built it | I'm Shannon Watson. I run a small business in Idaho, and I'm legally blind. Compliance websites are walls of text, so I wanted answers I could just hear, one at a time. |
| 3 | How it works | Under the hood, it's a small MCP server written in TypeScript. It uses the official MCP SDK, the same standard Alexa plus uses to talk to outside tools. |
| 4 | Four simple tools | There are four tools. Check my compliance, what's my next deadline, explain a term, and a quick accessibility check. Every answer is short enough to say out loud. |
| 5 | Ask: Idaho checklist | So let's try it. I'll ask about my out-of-state LLC in Idaho. It tells me there are four things to handle, starts with foreign registration, and gives me the fee. Then I just say next. |
| 6 | Ask: deadlines | What's my next deadline? The Idaho annual report, due October thirty-first, and it's free online. And New Mexico? Good news, there's no annual report there. |
| 7 | It won't guess | Every fee and rule points back to a real state source. And if it doesn't know, it says so. Ask about Texas, and it tells you it doesn't have verified data yet. No made-up numbers. |
| 8 | Website check | It can also look at a business website for missing image descriptions, unlabeled form fields, and messy headings, and it reads you the biggest problem first. |
| 9 | Done + Documented Voice | It's open source and free to use. That's Done + Documented Voice. Thanks so much for listening! |
